## What to build (one paragraph)

An employee drops receipt photos/PDFs into a web chat page. The system (1) reads each receipt with a vision LLM into a validated structure, (2) reads the
company's **policy documents** (Markdown with numbered clauses) with an LLM and turns them into structured, **quote-grounded** constraints, (3) classifies each
bill into the employee's policy categories with an LLM that explains itself, (4) enforces the constraints with deterministic code (caps per receipt/night/day/month,
partial reimbursement, FX conversion, age limit, exclusions, grade entitlements), (5) removes duplicates, groups bills into trips, and asks the employee only the
minimum questions needed, (6) lets the employee chat with an agent that can explain decisions, search the policy, and record answers, and (7) submits the
finished claim to a mock finance system (SQLite). Editing a policy document changes the outcome with **no code change**.
